# 손필기 노트와 수식 처리

전자회사 문서에는 회로 계산식이 자주 나오고, 원본이 손필기 노트(사진·스캔 이미지, 가끔 PDF)인 경우도 있다.
원칙은 같다: **버리지 않고, 추측하지 않고, 검산한다.**

## A. 손필기·스캔 원본 처리 순서
1. **쪽 이미지 준비:** 이미지는 그대로, PDF는 쪽마다 이미지로 렌더링(150dpi 이상). 휴대폰 사진의 회전 정보는 `crop_regions.py`가 자동 반영한다.
2. **판독(AI가 이미지를 직접 본다):** 쪽마다 아래 구역 목록을 만든다. 좌표는 이미지 대비 %(왼쪽 위 기준).
   | id | 종류 | 위치(x,y,w,h %) | 내용 | 판독 신뢰도 |
   |---|---|---|---|---|
   | T1 | 글 | 5,5,90,15 | (옮겨 적은 문장) | 높음 |
   | E1 | 수식 | 10,25,50,8 | (LaTeX) | 중간 |
   | G1 | 그래프 | 5,40,45,30 | 축·단위·눈금 값 | 중간 |
   | C1 | 회로 스케치 | 55,10,40,35 | 부품·연결 설명 | — |
   종류: 글 / 수식 / 그래프 / 회로 스케치 / 표 / 그림 / 화살표·연결선(무엇과 무엇을 잇는지 기록)
3. **잘라내기·확인:** `python scripts/crop_regions.py 원본.png 구역.json 출력폴더 [--enhance]`
   → **overlay.png를 반드시 열어** 상자가 대상을 빠짐없이 감싸는지 본다. 잘렸으면 좌표를 고쳐 다시 실행. 흐린 연필 필기는 `--enhance`.
4. **배치 규칙**
   - 글: 판독해서 텍스트로 옮긴다. 읽기 어려운 글자는 추측하지 말고 `[판독 불가]` 또는 `[판독 확인: ○○?]`로 표시하고 체크포인트 질문에 올린다.
   - 수식: LaTeX로 옮겨 아래 B 절차로 렌더링·검산. **원본 필기 수식 이미지도 유첨에 같이 남긴다**(옮겨 적기 오류 대비).
   - 그래프: 원본 잘라낸 그림을 기본으로 쓴다. 축 값이 명확히 읽힐 때만 PPT 차트로 다시 그리고 `[필기 판독값]`을 표시. 애매하면 다시 그리지 않는다.
   - 회로 스케치: **다시 그리지 않는다.** 잘라낸 원본을 쓰고, 설명은 옆에 텍스트로.
   - 화살표·연결선으로 이어진 내용은 그 관계(원인→결과, 조건→판정)를 흐름형 박스로 살린다.
   - 원본 쪽 전체 이미지는 유첨에 남긴다(사진·그림 보존 원칙과 같음).
5. **원본 목록표·사진 목록**(source-analysis.md)에 위 구역을 그대로 등록한다. 수식은 E번호, 그래프·스케치는 P번호로 연결.

## B. 수식 처리
1. **수식 목록**을 만든다.
   | id | 원본 위치 | LaTeX | 변수 정의·단위 | 대입값 | 원문 결과 | 재계산 | 판정 |
2. **검산(필수):** 대입값이 있는 계산은 `python scripts/check_calc.py 검산.json`으로 다시 계산한다. 단위는 SI로 맞춰 넣는다(mH→1e-3, kΩ→1e3).
   - 불일치는 보고서에 `[검산 불일치]`로 표시하고 체크포인트 질문에 올린다. 원문 결과를 몰래 고치지 않는다.
   - 단위가 맞지 않는 식(차원 불일치)도 같은 방식으로 표시한다.
   - 회로 설계 검토가 목적이면, 검산 결과를 부품 정격(데이터시트 값)과 비교하는 칸을 추가한다(예: 계산 전류 31A vs 정격 16A → 여유율).
3. **표현**
   - 간단한 식(V=IR, P=VI)은 PPT 텍스트로 쓴다(수정 가능).
   - 분수·루트·합·적분·첨자가 겹치는 식은 `python scripts/render_math.py --file 수식.json --outdir eq --color 1F3864`로 고해상도 PNG를 만들어 **`D.equation(pres, s, 영역, 파일, [w,h])`**로 넣는다(원래 크기 유지 — `D.photo`로 넣으면 박스에 맞춰 늘어나 글자가 본문보다 커진다). 출력된 픽셀 크기를 그대로 사용.
   - 설명용 첨자는 똑바로 쓴다: `I_\mathrm{peak}`, `R_\mathrm{DS(on)}`. 변수는 기울임 그대로.
   - 수식 아래에 **변수 설명 한 줄**(예: R_NTC: 돌입전류 제한 NTC 상온 저항)을 붙인다.
   - **원본 LaTeX는 슬라이드 노트에 반드시 남긴다**(이미지 수식은 직접 수정 불가).
   - 렌더링 오류(`[수식 오류]`)가 나면 LaTeX를 고친다. 오류를 무시하고 넘어가지 않는다.
4. **박스 패턴 — 계산 검증형:** 왼쪽 수식(렌더링) + 오른쪽 대입값·결과·판정(OK/NG 칩)·정격 대비 여유. 상무 10초 질문은 "그래서 정격 안에 들어오나?"
