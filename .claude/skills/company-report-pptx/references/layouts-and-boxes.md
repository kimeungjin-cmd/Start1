# 레이아웃·박스 채우기·시인성 패턴

## 레이아웃 5종 (deck.js의 layout 코드)
| 코드 | 쓰는 경우 |
|---|---|
| `1` | 덩어리 1개: 큰 차트, 흐름도, 일정표, 유첨 표 |
| `2-55` | **기본.** 대등 비교: 전/후, A안/B안, 근거/판단 비중이 비슷할 때 |
| `2-64` | 주+보조: 왼쪽 근거(차트·사진), 오른쪽 판단(해석·조치) |
| `2-73` | 큰 차트 + 짧은 요약 |
| `3` | 병렬 항목 3개. 박스당 글 3줄 이내 |
4개 이상이면 장을 나누거나 표로. 기본(2-55)에서 벗어날 때는 스토리보드에 이유 한 줄.
왼쪽 = 근거, 오른쪽 = 판단. 요약 띠는 쓰지 않는다(회사 양식에 없음).

## 박스 채우기 순서
1. 박스 메시지 1줄 = 이 박스가 증명하는 한 가지 (deck.js `boxes[].msg`, 남색 굵게 첫 줄)
2. 박스 메시지에 맞는 유형 선택
3. inner 영역의 70~85%만 채움. 꽉 차면 장을 나누고, 비면 유형을 바꾼다
4. 박스 메시지만 이어 읽어도 핵심 메시지가 증명되는지 확인

## 박스 안은 자유 디자인 — 단 최소 규칙 3개
1. **색은 의미로만**: 회사 메인색 = 결론·강조 / 회색 = 배경 정보 / 빨강 = 문제·리스크
2. **원본에 없는 숫자·날짜·담당 금지** → `[확인 필요]`
3. **박스 첫 줄 = 박스 메시지**
글자: 박스 메시지 13pt 굵게, 본문 11~13pt, 주석 10pt, 최소 10pt.

## 박스 유형
- 차트형: PPT 기본 차트(수정 가능). 강조 항목 1개만 메인색, 관련 항목 연한 메인색, 나머지 회색. 격자선·범례 제거, 값 라벨 직접 표시. 하단 주석에 기준·출처
- 표형: 6행 이내, 비교 기준 열을 왼쪽, 판정 열만 색. 넘치면 유첨
- 사진형: 원본 비율 유지, 정보 잘리는 크롭 금지, 표시는 도형으로 얹기, 사진 아래 한 줄 설명 + 원본 위치
- 4단 구조형: 원인 미확정 전용 (배제 원인 → 유력 가설 → 확인 계획 → 리스크 조치)
- 흐름형: 공정·시험 순서, 5단계 이내
- 개조식형: □ ○ - 3단계, 6줄 이내. 다른 유형으로 표현 가능하면 쓰지 않는다

## 시각 요소 최소 규칙
- **장마다 시각 요소 최소 1개**(차트·도식·사진·게이지·큰 숫자). 글만으로 채운 장은 검수에서 걸러낸다.
- 장 수를 줄이면(압축) 칸이 글로 차서 시각 요소가 사라진다. **압축할지, 장을 유지하고 시각화할지**는 목적으로 정한다: 임원 보고 → 압축 / 학습·설명 자료 → 시각화. 애매하면 묻는다.
- 원본에 없는 값(점수·감정·위험도 등)으로 그림을 그리면 반드시 "해석값, 정답 아님"을 적는다.
- 원본이 일부러 비워 둔 빈칸·질문(학습지, 퀴즈, 검토 질문)의 답은 시각 요소에 넣지 않는다. 그 칸은 '?'·점선으로 남긴다.
- 선 위 라벨은 흰 바탕을 깔거나 노드 안으로 옮겨 겹침을 피한다. 노드 사이 간격이 0.6인치보다 좁으면 선 라벨을 쓰지 않는다.

## 검수 질문 (매 장, 렌더링 이미지를 보고)
1. 그룹장이 이 장을 10초 본다면 물어볼 질문 3개는? (예: 몇 건? 어디까지? 언제 누가?)
2. 그 답이 문장을 읽지 않고도 눈에 보이는가? 아니면 위 패턴으로 바꾼다
3. 글자 넘침·잘림·한 단어만 다음 줄로 넘어감 없는가? 좌우 박스 첫 줄 높이가 맞는가?
4. 같은 내용이 두 박스에 반복되지 않는가?
5. **정렬 기준선이 있는가?** 나란한 상자들의 위·아래 끝, 상자 아래 밑줄·캡션의 좌우 끝, 원·도형 안 글자의 중심이 같은 선 위에 있는가

## 정렬 규칙 (그림을 그릴 때)
- HTML 그림에서 여러 열을 나란히 놓으면 **CSS grid로 열 폭을 고정**하고, 상자 아래 밑줄·설명은 같은 열에 넣는다. 여백(margin)으로 위치를 맞추지 않는다.
- 동심원·중첩 도형의 글자는 **각 띠의 중앙선(안쪽 반지름과 바깥 반지름의 가운데)에 2줄 블록으로** 놓고, 모든 원의 중심 x에 가운데 정렬한다. 좌표를 눈대중으로 찍지 않는다.
- 그림 안에 목록을 같이 그리지 않는다. 목록은 그림 옆에 PPT 텍스트로 두고, 항목 높이를 박스 높이에서 균등 분할한다(수정 가능 + 정렬 보장).
- 그림 좌표는 기준값(중심·열 폭·간격)에서 계산해서 쓴다.

## 숫자는 PPT, 그림은 SVG
- 숫자가 핵심인 차트·반복 보고 지표 → PPT 기본 차트
- 흐름도·구조도·원인 분석도 → HTML/SVG로 그려 삽입 가능. SVG 속 글자는 최소화하고 긴 설명은 PPT 텍스트로. 원본 데이터는 슬라이드 노트에 보존
