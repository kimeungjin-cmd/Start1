# 학습 모드 — 내가 배워야 할 주제를 이해하기 쉽게

보고용이 아니라 **사용자 본인의 학습**이 목적이다. 압축보다 이해가 우선이다.

## 원칙
- 장 수를 줄이지 않는다. 한 장 = 한 개념.
- **모든 장에 그림 1개 이상** (원리도, 흐름도, 비교 그림, 실제 사진).
- 원본이 부족하면 웹 검색으로 보충하고, 장 하단에 출처를 단다. 규격 조항·수치·부품 스펙은 검색한 원문으로 확인한다(관련 리서치 스킬이 있으면 같이 사용).
- 실물(부품·불량·설비·시험 구성)은 그림 대신 **실제 사진**을 우선한다.
- 회사 양식(헤더·박스 틀)은 그대로 쓰되, 박스 안은 시각화 최대.

## 장 흐름 (주제 하나 기준)
1. 큰 그림: 이게 뭐고 왜 중요한가 (한 장 요약 + 전체 구조도)
2. 원리: 어떻게 동작하나 (블록도·단계 그림, 필요하면 단계별로 여러 장)
3. 숫자 감각: 대표 수치를 기준과 함께 (정격, 스펙, 일반 범위)
4. 실무 연결: 내 업무(회로 설계 검토, 시험, 불량 분석)에서 어디에 쓰이나
5. 헷갈리는 점: 자주 틀리는 개념, 비슷한 것과의 차이
6. 자가점검: 질문 3~5개 (답은 노트에)

## 시각화 도구 선택
| 그림 | 도구 |
|---|---|
| 숫자 비교·추이 | PPT 기본 차트 |
| 단순 도형 흐름(박스·화살표 5개 이내) | PPT 도형 |
| 복잡한 원리도·계층도·단계별 변화·주석 많은 그림 | HTML(SVG/CSS)로 그려 `scripts/render_html.py`(Playwright)로 PNG 렌더링 |
| 실물 | 웹 이미지 검색·원본 사진 (출처 표기) |
| 웹 페이지의 공식 그림·표 | Playwright로 해당 영역만 캡처 가능. 저작권 있는 그림은 출처를 달고 학습용으로만 |

HTML 그림의 body에는 항상 `word-break: keep-all; overflow-wrap: anywhere;`를 넣는다(한국어가 단어 중간에서 끊기는 것 방지).

단계별 원리(예: 1→2→3단계로 바뀌는 동작)는 HTML 한 파일에 단계를 그리고 단계마다 캡처해 연속 장으로 넣으면 애니메이션처럼 이해된다.
