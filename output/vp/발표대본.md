# 시험항목 자동선정 AX 과제 성과보고 — 발표 대본

전체 3~4분. ○는 보고 전에 실제 값으로 채울 것. [멈춤]은 1~2초 쉬기.

## 1장 성과 요약 (60초)
보고드리겠습니다.
결론부터 말씀드리면, 시험항목 자동선정 AX 과제는 40개 모델 검증을 마쳤고, 시험항목 선정 업무에 공식 적용을 승인 요청드립니다. [멈춤]

결과는 두 가지입니다.
첫째, 과거 개발단계에서 사람이 선정한 시험을 빠짐없이 모두 포함했습니다. 냉장고, 세탁기, 에어컨, 조리기기 각 10개 모델 전부입니다.
둘째, 사람이 생각하지 못했던 연관 시험을 10% 더 찾았습니다. 이 부분이 Claude AI 분석의 역할입니다.
선정과 사례 검토 시간은 ○시간에서 ○분으로 줄었습니다.

## 2장 과제 배경 (30초, 질문이 없으면 짧게)
과제를 간단히 말씀드리면, 같은 변경점이라도 담당자 경험에 따라 시험 선정이 달라지는 문제가 있었습니다.
경험이 적으면 직접 영향만 보게 되고, 빠진 시험은 나중에 불량으로 드러납니다.
에이전트는 변경점을 넣으면 시험항목과 과거 유사 불량 사례를 함께 보여 주고, 최종 선정은 담당자가 합니다.

## 3장 검증 방법 (20초, 넘겨도 됨)
검증은 새로 정답을 만들지 않고, 실제 개발에 썼던 선정 목록과 같은 변경점으로 1:1 비교했습니다.

## 4장 연관 시험 (45초, 핵심 장)
추가 10%가 어떻게 나오는지 보여드리겠습니다.
사람은 주로 변경 부품과 해당 기능을 봅니다.
Claude AI는 설계 자료와 과거 사례를 읽고, 전원을 같이 쓰는 부위, 같은 기판의 열, 노이즈까지 따라갑니다.
예를 들어 ○○(제품군)에서 ○○을 바꿨을 때, 기존에는 ○○만 시험했는데 에이전트는 ○○까지 찾았습니다.
→ 사례는 하나만 말할 것. 표 전체를 읽지 않는다.

## 5장 적용 계획과 요청 (45초)
적용 계획입니다.
○월부터 신규 개발 모델에 공식 적용하고, 초기에는 베타 운영으로 담당자의 채택 결과를 받아 보완하겠습니다.
운영은 자동 리포트로 돌아가고, 제가 월 1회 30분 승인하는 구조입니다.
오늘 결정해 주실 것은 세 가지입니다. 표준 절차 등록, 적용 범위, 운영 방식입니다.

## 마무리 (10초)
정리하면, 사람 수준은 확보했고 그 이상을 찾는 것도 확인했습니다. 공식 적용 승인 부탁드립니다.
→ 말하고 나서 먼저 말을 잇지 말고 기다린다.

## 질문이 나올 때 (유첨 2와 같은 내용)
| 질문 | 첫 문장 |
|---|---|
| 사람 판단과 100% 일치하나? | "기존 시험은 100% 포함했습니다. 숙련자끼리도 100% 일치하지는 않아서, 목표는 일치가 아니라 빠뜨리지 않는 것입니다." |
| 추가 10%는 진짜 필요한가? | "샘플 ○건은 숙련자가 확인했고, 나머지는 적용 초기 담당자 채택률로 확인하겠습니다." |
| 검증은 누가 하나? | "별도 인력 없이, 담당자가 선정을 확정할 때 채택·기각을 체크하면 그게 검증 데이터가 됩니다." |
| AI가 틀리면? | "근거를 함께 보여 주고, 최종 선정은 담당자가 합니다." |
| 불량이 줄었나? | "아직 측정 전입니다. ○월에 첫 비교 결과를 보고드리겠습니다." |
| 유지보수 부담은? | "자동 리포트로 돌아가고, 제가 월 1회 30분 승인합니다." |
| 보안은? | "사내 AI 사용 기준에 따라 ○○ 승인을 받았습니다." (보고 전 확인 필수) |

모르는 질문이 나오면: **"그 부분은 ○○로 확인해서 ○월 ○일까지 말씀드리겠습니다."**
→ 변명하거나 길게 설명하지 않는다. 날짜를 말하면 끝.

## 1장만 할 시간밖에 없을 때 (30초판)
"40개 모델 검증을 마쳤습니다. 사람이 선정한 시험은 모두 포함했고, AI가 연관 시험을 10% 더 찾았습니다. ○월부터 공식 적용을 승인해 주십시오."

## 파트장 사전 리뷰 때 (하루 전)
"파트장님, 내일 부사장님 보고 1장 결론을 '40개 모델 검증 완료, 공식 적용 승인 요청'으로 잡았습니다.
이 방향 맞는지, 그리고 부사장님이 특히 물어보실 만한 게 있는지 여쭙고 싶습니다."
→ 파트장이 말한 질문은 그날 유첨 2에 추가한다.

## 리허설
- 보고 전날 소리 내어 두 번 읽는다. 한 번은 시간을 잰다(4분 넘으면 2·3장을 줄인다).
- 1장 첫 문장과 마무리 문장은 외운다. 나머지는 슬라이드를 보며 말해도 된다.
